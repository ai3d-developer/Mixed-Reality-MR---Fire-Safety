# 🔥 Mixed Reality – Fire Safety Training

An interactive Mixed Reality (MR) Fire Safety Training application developed using **Unity 3D and Blender**. This project aims to provide an immersive and interactive environment for learning fire safety procedures and understanding how to respond to fire emergencies.

## 🎯 Project Overview

The Mixed Reality Fire Safety project provides a virtual training environment where users can learn basic fire safety techniques, understand fire extinguisher operations, and experience emergency response scenarios through immersive 3D interactions.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Unity 3D | Application development and interaction |
| Blender | 3D modeling and asset creation |
| C# | Gameplay and interaction scripting |
| Mixed Reality | Immersive user experience |

## ✨ Key Features

- Interactive 3D fire safety environment.
- 3D fire extinguisher models.
- Immersive fire emergency simulation.
- Interactive object manipulation.
- Realistic fire and smoke effects.
- Fire safety awareness and training.

## 🎨 3D Asset Development

Blender is used to create and modify 3D assets, including fire safety equipment and environmental objects. These assets are imported into Unity for scene development, animation, and interaction.

## 🚀 Development Workflow

1. Create and model 3D objects using Blender.
2. Import 3D assets into Unity.
3. Design the fire safety training environment.
4. Implement interactions using C# scripts.
5. Add fire, smoke, and visual effects.
6. Test and build the application.
